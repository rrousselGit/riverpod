오랜 기다림 끝에 드디어 Riverpod의 첫 안정 버전이 출시되었습니다 👏

전체 변경 사항은 [Changelog](https://pub.dev/packages/flutter_riverpod/changelog#100)를 참고하세요.  
이 페이지에서는 기존 Riverpod 애플리케이션을 0.14.x 버전에서 1.0.0 버전으로
마이그레이션하는 방법을 중점적으로 다룹니다.

## 마이그레이션 도구로 프로젝트를 새 문법으로 자동 업그레이드하기 {#using-the-migration-tool-to-automatically-upgrade-your-project-to-the-new-syntax}

변경 사항을 하나씩 설명하기 전에, Riverpod에는 프로젝트를 자동으로 마이그레이션해 주는
커맨드라인 도구가 있다는 점을 알아 두면 좋습니다.

### 커맨드라인 도구 설치하기 {#installing-the-command-line-tool}

마이그레이션 도구를 설치하려면 다음을 실행하세요.

```sh
dart pub global activate riverpod_cli
```

이제 다음 명령을 실행할 수 있습니다.

```sh
riverpod --help
```

### 사용법 {#usage}

커맨드라인 도구를 설치했으니 이제 사용해 봅시다.

- 먼저 마이그레이션할 프로젝트를 터미널에서 엽니다.
- Riverpod을 업그레이드하지 **마세요**.  
  마이그레이션 도구가 Riverpod 버전을 대신 업그레이드해 줍니다.

  :::danger 경고
  Riverpod을 업그레이드하지 않는 것이 중요합니다.  
  이미 1.0.0 버전을 설치했다면 도구가 제대로 실행되지 않습니다.
  따라서 도구를 실행하기 전에 반드시 이전 버전을 사용하고 있는지 확인하세요.
  :::

- 프로젝트에 오류가 없는지 확인합니다.
- 다음을 실행합니다.
  ```sh
  riverpod migrate
  ```

그러면 도구가 프로젝트를 분석하고 변경 사항을 제안합니다. 예를 들어 다음과 같은 내용이 표시될 수 있습니다.

```diff
-Widget build(BuildContext context, ScopedReader watch) {
+Widget build(BuildContext context, Widget ref) {
-  MyModel state = watch(provider);
+  MyModel state = ref.watch(provider);
}

Accept change (y = yes, n = no [default], A = yes to all, q = quit)?
```

변경을 수락하려면 <kbd>y</kbd>를 누르고, 거절하려면 <kbd>n</kbd>을 누르면 됩니다.

## 변경 사항 {#the-changes}

CLI로 프로젝트를 자동 업그레이드하는 방법을 살펴보았으니,
이제 필요한 변경 사항을 자세히 알아보겠습니다.

### 문법 통일 {#syntax-unification}

Riverpod 1.0.0 버전은 provider와 상호작용하는 문법을 통일하는 데 초점을 맞췄습니다.  
이전에는 Riverpod에 `ref.watch(provider)`, `useProvider(provider)`, `watch(provider)`처럼
provider를 읽는 문법이 비슷하면서도 조금씩 다른 형태로 여러 가지 있었습니다.  
1.0.0 버전부터는 `ref.watch(provider)` 하나만 남고 나머지는 제거되었습니다.

따라서 다음과 같이 바뀌었습니다.

- `useProvider`가 제거되고 `HookConsumerWidget`으로 대체되었습니다.

  이전:

  ```dart
  class Example extends HookWidget {
    @override
    Widget build(BuildContext context) {
      useState(...);
      int count = useProvider(counterProvider);
      ...
    }
  }
  ```

  이후:

  ```dart
  class Example extends HookConsumerWidget {
    @override
    Widget build(BuildContext context, WidgetRef ref) {
      useState(...);
      int count = ref.watch(counterProvider);
      ...
    }
  }
  ```

- `ConsumerWidget`의 `build`와 `Consumer`의 `builder` 시그니처가 바뀌었습니다.
 
  이전:

  ```dart
  class Example extends ConsumerWidget {
    @override
    Widget build(BuildContext context, ScopedReader watch) {
      int count = watch(counterProvider);
      ...
    }
  }

  Consumer(
    builder: (context, watch, child) {
      int count = watch(counterProvider);
      ...
    }
  )
  ```

  이후:

  ```dart
  class Example extends ConsumerWidget {
    @override
    Widget build(BuildContext context, WidgetRef ref) {
      int count = ref.watch(counterProvider);
      ...
    }
  }

  Consumer(
    builder: (context, ref, child) {
      int count = ref.watch(counterProvider);
      ...
    }
  )
  ```

- `context.read`가 제거되고 `ref.read`로 대체되었습니다.

  이전:

  ```dart
  class Example extends StatelessWidget {
    @override
    Widget build(BuildContext context) {
      SomeButton(
        onPressed: () => context.read(provider.notifier).doSomething(),
      );
    }
  }
  ```

  이후:

  ```dart
  class Example extends ConsumerWidget {
    @override
    Widget build(BuildContext context, WidgetRef ref) {
      SomeButton(
        onPressed: () => ref.read(provider.notifier).doSomething(),
      );
    }
  }
  ```

### StateProvider 변경 {#stateprovider-update}

[StateProvider]가 [StateNotifierProvider]와 동작이 같도록 변경되었습니다.

이전에는 `ref.watch(StateProvider)`가 `StateController` 인스턴스를 반환했습니다.
이제는 `StateController`의 상태만 반환합니다.

마이그레이션하는 방법은 몇 가지가 있습니다.  
코드에서 상태를 변경하지 않고 읽기만 한다면, 다음 코드를

```dart
final provider = StateProvider<int>(...);

Consumer(
  builder: (context, ref, child) {
    StateController<int> count = ref.watch(provider);

    return Text('${count.state}');
  }
)
```

다음과 같이 바꾸면 됩니다.

```dart
final provider = StateProvider<int>(...);

Consumer(
  builder: (context, ref, child) {
    int count = ref.watch(provider);

    return Text('${count}');
  }
)
```

또는 새로 추가된 `StateProvider.state`를 사용해 기존 동작을 유지할 수도 있습니다.

```dart
final provider = StateProvider<int>(...);

Consumer(
  builder: (context, ref, child) {
    StateController<int> count = ref.watch(provider.state);

    return Text('${count.state}');
  }
)
```
