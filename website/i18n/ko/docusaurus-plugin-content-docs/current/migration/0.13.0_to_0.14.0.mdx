Riverpod `0.14.0` 버전이 출시되면서 [StateNotifierProvider]를 사용하는 문법이 바뀌었습니다
(자세한 설명은 https://github.com/rrousselGit/riverpod/issues/341 을 참고하세요).

이 문서 전체에서 다음 [StateNotifier]를 예로 사용합니다.

```dart
class MyModel {}

class MyStateNotifier extends StateNotifier<MyModel> {
  MyStateNotifier(): super(MyModel());
}
```

## 변경 사항 {#the-changes}

- [StateNotifierProvider]가 제네릭 매개변수를 하나 더 받습니다. 이 매개변수는
  [StateNotifier]의 상태 타입이어야 합니다.

  이전:

  ```dart
  final provider = StateNotifierProvider<MyStateNotifier>((ref) {
    return MyStateNotifier();
  });
  ```

  이후:

  ```dart
  final provider = StateNotifierProvider<MyStateNotifier, MyModel>((ref) {
    return MyStateNotifier();
  });
  ```

- [StateNotifier]를 얻으려면 이제 `myProvider` 대신 `myProvider.notifier`를 읽어야 합니다.

  이전:

  ```dart
  Widget build(BuildContext context, ScopedReader watch) {
    MyStateNotifier notifier = watch(provider);
  }
  ```

  이후:

  ```dart
  Widget build(BuildContext context, ScopedReader watch) {
    MyStateNotifier notifier = watch(provider.notifier);
  }
  ```

- [StateNotifier]의 상태를 구독하려면 이제 `myProvider.state` 대신 `myProvider`를 읽어야 합니다.

  이전:

  ```dart
  Widget build(BuildContext context, ScopedReader watch) {
    MyModel state = watch(provider.state);
  }
  ```

  이후:

  ```dart
  Widget build(BuildContext context, ScopedReader watch) {
    MyModel state = watch(provider);
  }
  ```

## 마이그레이션 도구로 프로젝트를 새 문법으로 자동 업그레이드하기 {#using-the-migration-tool-to-automatically-upgrade-your-projects-to-the-new-syntax}

0.14.0 버전과 함께 프로젝트 마이그레이션을 도와주는
Riverpod 명령줄 도구가 출시되었습니다.

### 명령줄 도구 설치하기 {#installing-the-command-line}

마이그레이션 도구를 설치하려면 다음을 실행하세요.

```sh
dart pub global activate riverpod_cli
```

이제 다음 명령을 실행할 수 있습니다.

```sh
riverpod --help
```

### 사용법 {#usage}

명령줄 도구를 설치했으니 이제 사용해 보겠습니다.

- 먼저 마이그레이션할 프로젝트를 터미널에서 엽니다.
- Riverpod을 직접 업그레이드하지 **마세요**.  
  마이그레이션 도구가 Riverpod 버전을 대신 업그레이드해 줍니다.
- 프로젝트에 오류가 없는지 확인합니다.
- 다음을 실행합니다.
  ```sh
  riverpod migrate
  ```

그러면 도구가 프로젝트를 분석하고 변경 사항을 제안합니다. 예를 들어 다음과 같은 내용이 표시될 수 있습니다.

```diff
Widget build(BuildContext context, ScopedReader watch) {
-  MyModel state = watch(provider.state);
+  MyModel state = watch(provider);
}

Accept change (y = yes, n = no [default], A = yes to all, q = quit)? 
```

변경을 수락하려면 <kbd>y</kbd>를 누르세요. 거부하려면 <kbd>n</kbd>을 누르세요.
