# Flutter Skeleton App with Riverpod

This tutorial demonstrates how to convert the default Flutter Skeleton template to use Riverpod for state management.

## Setup

Add Riverpod to your `pubspec.yaml`:

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_riverpod: ^2.5.1
  riverpod_annotation: ^2.3.5

dev_dependencies:
  build_runner: ^2.4.9
  riverpod_generator: ^2.4.0
